📗 내신 문제 생성기

학습 자료(PDF·이미지·텍스트)를 올리면 고난도 내신형 시험지 + 해설지를 자동으로 만들어 드립니다.

1 API 키 설정

문제 생성에는 Anthropic Claude API가 사용됩니다. console.anthropic.com에서 발급한 본인의 API 키를 입력하세요. 키는 서버로 전송되지 않고 이 브라우저(localStorage)에만 저장됩니다.

2 학습 자료 업로드

📂

파일을 여기로 끌어다 놓거나 클릭해서 선택

PDF · 이미지(JPG/PNG/WebP/GIF) · 텍스트(.txt/.md) — 여러 개 가능, 총 25MB 이하 권장

    또는 텍스트를 직접 붙여넣기

    4 생성된 시험지

    PDF 저장: 인쇄 대화상자에서 대상(프린터)을 “PDF로 저장”으로 선택하세요.

    안내

    • 업로드한 자료는 문제 생성을 위해 Anthropic API로만 전송되며, 별도의 서버에 저장되지 않습니다.
    • API 사용량에 따라 Anthropic 요금이 부과됩니다 (자료 분량과 문항 수에 비례).
    • 생성된 문제는 반드시 원본 자료와 대조하여 검토 후 사용하세요.
